Personal Research Backup is a personal workflow for preserving research files in the owner's Google Drive using restic and rclone.

This website explains the application and its use of Google account access. It does not perform backups, accept uploads or offer a public sign-in service.

Read the privacy policy →

How the workflow is designed

Three steps, one private destination.

  1. Select local files

    The owner chooses research artifacts on their own computer. Credentials and public website files are kept separate from the backup selection.

  2. Encrypt with restic

    Restic encrypts backup contents and repository metadata locally before upload. The owner keeps the repository password separately for recovery.

  3. Transfer with rclone

    Rclone uses the owner's Google authorization to store the encrypted repository in Google Drive. Google can still observe account and service activity, including storage usage.

Access with a specific purpose

The application requests the Google Drive drive.file permission to create and manage its backup files, and any files the owner explicitly authorizes for the application. It does not request permission to read every file in the owner's Drive.

OAuth credentials and tokens are stored in the owner's protected local rclone configuration. They are never part of this public website.

Setup in progress. Nightly automation is planned. A completed backup, tested restore and active schedule have not yet been confirmed. This website is not evidence of backup protection.
